## 🚀 배포 방법

### GitHub Pages를 통한 배포
1. GitHub Desktop에서 저장소 생성
2. 파일들을 커밋하고 푸시
3. GitHub 저장소 설정에서 Pages 활성화
4. `index.html`을 루트 파일로 설정

### 로컬에서 실행
```bash
# 프로젝트 폴더로 이동
cd html

# 로컬 서버 실행 (Python 사용)
python -m http.server 8000

# 또는 Node.js 사용
npx serve .
```
